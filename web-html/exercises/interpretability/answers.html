Interpretability - Answers

  1. Why is interpretability important?
  • To understand the rationale behind the model prediction
  • To prove model prediction correctness
  • To ensure the model takes into account the correct information
  • To check whether the model propagates biases
  • Becuase it is can be required legally

Explanation: All of the options are correct. Interpretability methods can helps us understand why the model made the given prediction better. Moreover, in some fields it might be legally required to give reasoning behind why a model behaves a certain way.

  1. Which of the following is true for interpreting linear models using learned weights?
  • It’s a local rational because it works for all input points
  • Is not inherently explainable
  • Linear models are easily explainable
  • A lot of complicated models are explained using linear model as a local approximation

Explanation: Definition of global rationale given in this class is a rationale that can be applied to explain all predictions. By looking at the learned weights of a linear model we can explain predictions for all outputs, so it is a global rationale. Since the weights are part of the model's internal reasoning, this rationale is considered inherently explainable. Finally, this is the easiet type of rationale and the most explainable, so it's used a lot to approximately explain more complicated models.

  1. Which of the following is true about Class Activation Maps?
  • CAM does not require a whitebox model
  • The map with the highest weight contributes the most to the made prediction
  • CAM can be generalized to see which part of the image contributes the most to the made prediction

Explanation: CAM requires a whitebox model because we need to get the activation maps from the model. By creating the General Activation Pooling layer, we can get the weights applied to each map. Whe map with the highert weight contributes the most to the made prediction. Further generalization to Grad-CAM gives rationale of which part of the image contributes the most to the made prediction by producing a heatmap.

  1. Which of the following is true about Local Interpretable Model-agnostic Explanations (LIME) for CNN?
  • LIME can be done only with a blackbox model
  • Create local neighbors by randomly masking patches of an image
  • Need to fit a linear model that would give similar predictions to the CNN model near the input image
  • LIME gives a global rationale

Explanation: LIME can be done with a whitebox model as well, as long as, we can just give input and get prediction from the model. Since LIME is applied one image at a time, it gives a local rationale of which patches of the specific image affected the prediction made.

  1. LIME can only be applied in CNNs.
  • True
  • False

Explanation: LIME can also be applied for text and other types of inputs where a patch can be a meangingful unit.

  1. Which of the following is true about getting rationales from predictions?
  • Rationals should be short
  • Rationales do not need to be enough to make correct predictions
  • Rationale is given during training

Explanation: For getting rationals from predictions, these rationales must be sufficient to make the correct prediction. Rationales are not given during the training of the model. Instead, they are inferred from the prediction made.

  1. What architecture change can help to train a model to generate rationales from predictions?
  • Add a part that will take input and directly give a prediction
  • Make a model that takes in a random rationale and gives a prediction
  • Make the last part of the model take in rationale produced from the input and produce a prediction
  • Add a part that will take input and give a rationale

Explanation: input \(x\) -> rationale generator -> rationale \(z\) -> predictor -> prediction \(y\) is a type of architecture that can help train a rationale generator using cost object covered in class

$$ cost (z, y) = loss(z, y) + \lambda_1 |z|_1 + \lambda_2 \sum_i |z_i-z_{i-1}| $$
  1. The cost covered in the lecture to use for training a model to get rationales from predictions is the following
$$ cost (z, y) = loss(z, y) + \lambda_1 |z|_1 + \lambda_2 \sum_i |z_i-z_{i-1}| $$

Match each of the parts of the cost to what they represent

| parts of the cost | | --- | | \(loss(z, y)\) | | \(\lambda_1 \|z\|_1\) | | \(\lambda_2 \sum_i \|z_i-z_{i-1}\|\) |

|represent| | --- | | coherency | | sparsity | | sufficiency |

Answer: \(loss(z, y)\) -> sufficiency, \(\lambda_1 |z|_1\) -> sparsity, \(\lambda_2 \sum_i |z_i-z_{i-1}|\) -> coherency

Explanation: As we said before, we need the rationales to be short and sufficient to make the right prediction. Here the \(loss(z, y)\) makes sure that the produced rationale is enough to make correct prediction, and \(\lambda_1 |z|_1\), \(\lambda_2 \sum_i |z_i-z_{i-1}|\) make sure that the rationale is short and continuous.

  1. Rationales from predictions can only be applied to cooperative games
  • True
  • False

Explanation: Getting rationales from prediction can be applied to anything represented as text, e.g. product reviews, disease prediction, etc.

  1. Which of the following is true about data attribution methods?
  • In practice, these methods process data in batches
  • These methods help to understand whether the problem of the model is in the data vs something else, like model architecture
  • Try to find which training datapoint that was the least important for the prediction

Explanation: Data attribution methods generally try to find training datapoint that was the most important for a given prediction. Since training set size is usually very big and these methods normally require retraining of a model, in practice, we need to process the data in batches and see which batch was the most important for a given prediction.

  1. Why is interpretability challenging?
  • Reasoning is too complicated to understand
  • People already trust a lot of machines even if they don't know how it works, so interpretability is unnecessary
  • Efficacy of decision making might decrease because the rationale sounds realistic and sways original opinion
  • All of the above

Explanation: All of these are potential challenges and pushbacks used against interpretability methods. However, these methods are still useful to answer specific questions and help with model selection and ensuring some understanding of the given models.
