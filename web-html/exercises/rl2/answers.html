  1. In model-based estimation, for the following setup, if moving UP from state 3 ended up: in state 1 with reward 1, three out of 10 times, in state 1 with reward 0.5, two out of 10 times, in state 2 with reward 0.5, one out of 10 times, in state 4 with reward 2.0, one out of 10 times, and in state 5 with reward -1, three out of 10 times. What is the p’(3, action, reward)?

Answer: p'(3, UP, 1) = \(\frac{3}{10}\), p'(3, UP, 0.5) = \(\frac{3}{10}\), p'(3, UP, 2) = \(\frac{1}{10}\), p'(3, UP, -2) = \(\frac{3}{10}\).
Explanation: To calculate p'(reward) we need to calculate the fraction of times each reward appeared after taking an action from state 3. So p'(3, UP, 1) = \(\frac{3}{10}\), p'(3, UP, 0.5) = \(\frac{2+1}{10} = \frac{3}{10}\), p'(3, UP, 1) = \(\frac{1}{10}\), p'(3, UP, -1) = \(\frac{3}{10}\).

  1. Given your response to the previous question, what is the expected reward of taking action UP from state 3?

Answer: 0.35.
Explanation: To calculate the expected reward, we need to multiply the probabilities we found by the reward and sum them up, so \(E[reward] = \frac{3}{10}*1 + \frac{3}{10}*0.5 + \frac{1}{10}*2 + \frac{3}{10}*(-1) = \frac{3.5}{10} = 0.35\).

5. In model-free estimation, for the same setup and history, what is the expected reward of taking action UP from state 3?

Answer: 0.35.
Explanation: In model-free estimation, to calculate the expected reward, we just need to take the average of all rewards, so \(\frac{1 + 1+ 1 + 0.5 + 0.5 + 0.5 + 2 + (-1) + (-1) + (-1)}{10} = \frac{3.5}{10} = 0.35\).

Note: We got same value for both model-free and model-based estimation. This is also generally true and the reason we can use the new Q-value formula.

6. For the same setup, alpha = 0.5 and gamma = 0.5, if in the current iteration you have the following Q-values, what is Q(3, UP) if you ended up in state 1 and got a reward of 1?

| | UP | RIGHT | DONW | LEFT | |--|--|--|--|--| |1| 0 | 0 | 0 | 0 | |2| 1.1 | 0.9 | -0.2 | 0 | |3| 1.2 | 0 | 0 | 0 | |4| 0 | 0 | 0 | 0 | |5| 0 | 0 | 0 | 0 |

Answer: 1.1.
Explanation: Reminder, \(Q(s, a) \leftarrow (1-\alpha) Q(s,a) + \alpha (R(s, a, s') + \gamma \max_{a'} Q_i(s', a'))\). So,

$$ Q(3, UP) = (1-0.5) * 1.2 + 0.5 * (1 + 0.5 * (max\{Q(1, UP), Q(1, RIGHT), Q(1, DOWN), Q(1, LEFT)\})) \\ = 0.5 * 1.2 + 0.5 * (1 + 0.5 * (max\{0, 0, 0, 0\})) \\ = 1.1 $$

Answer: 1.125.
Explanation: Reminder, \(Q(s, a) \leftarrow (1-\alpha) Q(s,a) + \alpha (R(s, a, s') + \gamma \max_{a'} Q_i(s', a'))\). So,

$$ Q(3, UP) = (1-0.5) * 1.2 + 0.5 * (0.5 + 0.5 * (max\{Q(2, UP), Q(2, RIGHT), Q(2, DOWN), Q(2, LEFT)\})) \\ = 0.5 * 1.2 + 0.5 * (0.5 + 0.5 * (max\{1.1, 0.9, -0.2, 0\})) \\ = 0.6 + 0.5*(0.5 + 0.5*1.1) \\ = 1.125 $$

  1. Which of the following is true about the alpha hyperparameter in the Q-value iteration formula?
  • If alpha is closer to zero, we care about the past samples more
  • If alpha is closer to zero, we care about new samples more
  • If alpha is closer to one, we care about the past samples more
  • If alpha is closer to one, we care about new samples more

Explanation: As can be seen from the previous problems, when alpha is closer to zero the new sample is almost ignored and we rely mostly on past knowledge. In contrast, when alpha is closer to 1, previously experience is mostly ignored and new samples are taken into account. Both are important extremes to remember because different settings and fields might require different alpha's.

  1. In a deep Q-learning setting, what is different about the Q-value?
  • Q-value is no longer represented as a table
  • Q-value is now represented parametrically as a function
  • No hyperparameters are used for deep Q-learning
  • All of the above

Explanation: Because in setting like the game of go it is computationally expensive to calculate the full Q-table, in deep Q-learning we represent the Q as a parametric function and do not calculate the full table at once.

  1. Which of the following formulas is used for finding the Q-value in deep Q-learning?
  • \(L = (R(s, a) + \gamma \max_{a'} Q(s', a') + Q(s, a))^2\)
  • \(L = (R(s, a) + \gamma \max_{a'} Q(s', a') + Q(s, a))\)
  • \(L = (R(s, a) + \gamma \max_{a'} Q(s', a') - Q(s, a))^2\)
  • \(L = (R(s, a) + \gamma \max_{a'} Q(s', a') - Q(s, a))\)

Explanation: \(L = (R(s, a) + \gamma \max_{a'} Q(s', a') - Q(s, a))^2\) is Bellman equations converted to a loss function. If the learned Q is close to Bellman equation it will minimize the given loss.

  1. Match the following issues that can arise in a deep Q-learning setting to the respective solution.

| issue | solution | |--|--| | Short-term actions are related | train another Q-value that is updated slowly | | Moving target problem | use Monte-Carlo| | Hard to perfect local behavior | sample actions to take into account randomly from a continuous set |

Answer:

  • Short-term actions are related -> sample actions to take into account randomly from a continuous set
  • Moving target problem -> train another Q-value that is updated slowly
  • Hard to perfect local behavior -> use Monte-Carlo
