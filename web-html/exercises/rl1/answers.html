  1. What is the difference between RL and a typical supervised learning setup?
  • RL does not need training (does not learn anything) while supervised learning does
  • Supervised learning expects labeled examples while RL does not
  • RL tries different actions and looks at the outcome
  • All of the above

Explanation: RL still does some learning, but it no longer uses labeled example. Instead, it tries different actions and learns based on the outcomes of the actions.

  1. What are the main distinctive factors of RL?
  • In RL, feedback is delayed
  • In RL, there is freedom to select actions from a given set
  • In RL, feedback is immediate
  • In RL, there is freedom to select any action

Explanation: The feedback from action of further states come back delayed and actions only from a given action set can be taken.

  1. What is the main distinctive factor of MDP?
  • No matter where you start the optimal action is determined by the current state
  • Best action depends on the start state
  • Next action's result depends on all previous states
  • Next action's result only depends on the current state

Explanation: Markdov Decision Processes only take into account current state when taking a new action because all previous ones are considered to not affect your results. While this assumption is made for simplicity, later in the lectures we will see how it can be unrealistic.

  1. For the same setup from the lecture, if the current Q table is the following, in the next iteration, what will be the value of Q(warm, fast) for gamma 0.1?

| | slow | fast | |--|--|--| |cool| 0 | 0 | |warm| 0 | 0 | |overheated| 0 | 0 |

You get +1 reward for becoming warm or cool and -100 reward if you overheat. Once you overheat, the car is broken, so you cannot do anything and get no reward from that state.

Answer: -100.
Explanation: Reminder that the formula for computng Q-value in Q-value iteration is the following:

$$ Q_t(s, a) = R(s, a) + \gamma \sum_{s'} T(s, a, s') \max_{a'} Q_{t-1}(s', a') $$

So \(Q(warm, fast) = R(warm, fast) + 0.1 * (T(warm, fast, overheated) \max\{Q(overheated, slow), Q(overheated, fast)\}) = -100 + 0.1 * 1 * 0 = -100 \) becuase if go fast while the car is warm, it gets overheated and the Q(overheated, _) = 0 since Q-table is all 0's currently.
