What To Notice

Learned Surrogate Weights

Positive weights raise the selected animal score in this local neighborhood. Negative weights lower it. The explanation budget only emphasizes the top few.

Neighborhood Fidelity

Each point is one masked image. The surrogate should match the black-box model best on points that stay closest to the original image.

LIME Neighborhood Builder

Choose a sample or upload a clear animal photo. The image is divided into a visible 4x4 grid so you can see exactly what gets masked. LIME then queries the classifier on many masked versions of that image and explains one selected animal score locally.
