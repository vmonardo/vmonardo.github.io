Batch Gradient Demo

The top plot shows a simple linear regression dataset. The bottom plot shows the MSE loss surface over parameters (w, b). The black arrow is the full-batch gradient. The orange arrows are gradients from sampled mini-batches at the same parameter point.

Gradient Summary

How To Read It

Vanilla gradient descent would use the full black arrow for each update. SGD uses one data point or a small mini-batch, so each orange arrow is a possible gradient estimate instead.
Small batches = noisier
Large batches = steadier
SGD uses sampled data
