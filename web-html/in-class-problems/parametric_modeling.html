Problem 1 Successive gradient steps

In batch gradient descent, we take steps using a constant learning rate \(\eta,\) so that:

$$ \theta^{(t+1)} = \theta^{(t)} - \eta \nabla_\theta f(\theta^{(t)}) \; . $$

In the following, assume that \(f\) is an arbitrary differentiable function. Assume that we are considering a single iteration of gradient descent evaluated at a fixed value of \(\theta^{(t)}\; \).

a) For extremely small \eta, what will generally be true?

  • \(f(\theta^{(t)}) \geq f(\theta^{(t+1)})\)
  • \(f(\theta^{(t)}) \leq f(\theta^{(t+1)})\)
  • cannot say

Answer: \(f(\theta^{(t)}) \geq f(\theta^{(t+1)})\).
Explanation: For extremely small \(\eta\), the gradient descent will never worsen (increase) the value of the function it is minimizing. Intuitively, there will always be a small enough learning rate such that a step in the direction of steepest descent decreases (or more precisely, does not increase) the function value.

b) For very very big \eta, what will generally be true?

  • f(\theta^{(t)}) \geq f(\theta^{(t+1)})
  • f(\theta^{(t)}) \leq f(\theta^{(t+1)})
  • cannot say

Answer: cannot say.
Explanation: For very very big \eta, we cannot say anymore whether the value of the function is going to decrease or increase. (Consider starting at \(x=-1\) along \(f(x) = x^2\) and taking \(\eta=100\).)

Problem 2 Descent into Madness

Let's consider gradient descent algorithm on a one-dimensional function:

$$ f(\theta) = (2\theta + 3)^2 \,\, . $$

Note that here \(\theta\) is one dimensional, but gradient descent can find local minima for general multi-input scalar-output functions too.

a) Now let's formulate the update rule that will be executed on every step when performing gradient descent on our specific \(f(\theta)\) above, using \(\eta\) as the learning rate parameter. \(\theta_{new} =\) .

Answer: \(theta - eta*(8*theta + 12)\).
Explanation: Using basic rules of differentiation we find \(\nabla_{\theta} f(\theta) = \frac{df(\theta)}{d\theta} = 2 \cdot (2\theta +3) \cdot 2\). Combining this with the update rule \(\theta^{(1)} = \theta^{(0)} - \eta \nabla_{\theta} f(\theta^{(0)})\), we get the expression above.

For the rest of the questions in this section, we will start with \(\theta=1\) and \(\eta=0.1\) Recall that \(f(\theta) = (2\theta + 3)^2 \,\, .\)

b) What is the value of \(f(\theta)\) before running any iterations of gradient descent?

Answer: 25.
Explanation: Plugging into the function: \(f(1) = (2*1+3)^2 = 25\).

Recall that \(f(\theta) = (2\theta + 3)^2 \,\, .\)

c) After a single gradient descent update, what is the value of \(\theta\)?

Answer: -1.
Explanation: Plugging into the update rule: \(\theta^{(1)} = \theta^{(0)} - \eta(8\theta^{(0)}+12) = 1 - .1(20) = -1\).

d) After that update, what is the value of the function \(f(\theta)\)?

Answer: 1.
Explanation: Plugging into \(f\) once again: \(f(-1) = (2(-1)+3)^2 = 1\).

Problem 3 2D gradient descent

Let’s consider gradient descent when the dimension of the input is 2:

$$ \theta = \begin{bmatrix} \theta_1 \\ \theta_2 \end{bmatrix} \;\;. $$

Suppose we have \(f(\theta)\) and we are trying to find the values of \(\theta_1\) and \(\theta_2\) that minimize it. Consider

$$ f(\theta) = -3\theta_1 - \theta_1 \theta_2 + 2 \theta_2 + \theta_1^2 + \theta_2^2 \;\;. $$

a) What is the first component of \(\nabla_\theta f(\theta)\) ?

Answer: \(-3 - theta_2 + 2*theta_1\).
Explanation: $ \frac{\partial}{\partial\theta_1}\left(-3\theta_1 - \theta_1 \theta_2 + 2 \theta_2 + \theta_1^2 + \theta_2^2\right) = -3 - \theta_2 + 2 \theta_1 ; .$

b) What is the second component of \(\nabla_\theta f(\theta)\) ?

Answer: \(-theta_1 + 2 + 2*theta_2\).
Explanation: \(\frac{\partial}{\partial \theta_2} (-3\theta_1 - \theta_1 \theta_2 + 2 \theta_2 + \theta_1^2 + \theta_2^2) = - \theta_1 + 2 + 2\theta_2 \; .\)

c) What is \(f\left(\begin{bmatrix} 1 \\ 1 \end{bmatrix}\right)\)?

Answer: 0.
Explanation: \(f\left(\begin{bmatrix} 1 \\ 1 \end{bmatrix}\right)= -3(1)-(1)(1)+2(1)+(1)^2 + (1)^2 = -3 - 1 + 2 + 1 + 1 = 0\).

d) If we started at \(\theta = \begin{bmatrix} 1 \\ 1 \end{bmatrix}\) and took a step of gradient descent with learning rate 0.1, what would the next value of \(\theta\) be?

Answer: [1.2, 0.7].
Explanation:

$$ \theta_{new} = \theta_{old} - 0.1 \begin{bmatrix} (-3 -1 + 2) \\ (-1 + 2 + 2) \end{bmatrix} = \begin{bmatrix}1 \\ 1\end{bmatrix} - \begin{bmatrix} -0.2 \\ 0.3 \end{bmatrix} = \begin{bmatrix} 1.2 \\ 0.7 \end{bmatrix} $$

e) What is \(f\left(\begin{bmatrix} 1.2 \\ 0.7 \end{bmatrix}\right)\)?

Answer: -1.11.
Explanation: \(f\left(\begin{bmatrix} 1.2 \\ 0.7 \end{bmatrix}\right) = -3*(1.2)-(1.2)*(0.7)+2*(0.7)+(1.2)^2 + (0.7)^2 = -1.11\)

f) If we started at \(\theta = \begin{bmatrix} 1 \\ 1 \end{bmatrix}\) and took a step of gradient descent with learning rate 1.0 instead, what would the next value of \(\theta\) be?

Answer: [3, -2].
Explanation: \([1, 1]^T - [-2, 3]^T = [3, -2]^T\).

g) What is \(f\left(\begin{bmatrix} 3 \\ -2 \end{bmatrix}\right)\)?

Answer: 6.
Explanation: \(f\left(\begin{bmatrix} 3 \\ -2 \end{bmatrix}\right) = -3*(3)-(3)*(-2)+2*(-2)+(3)^2 + (-2)^2 = 6\)

Problem 4 Hypothesis classes

For each of the following hypothesis classes, write down an expression for the partial derivative of the squared loss \(L_2\) on a single example \((x, y)\) with respect to parameter vector \(\theta\) using the symbols: x, y and theta.

Remember that you can use * for element-wise multiplication, @ for dot product, and transpose(a) for transpose of a vector or array:

$$ h(x; \theta) = \theta^Tx + \theta^T (x *x) $$

Note that \(x*x\) here is computed from the input vector by squaring each component. In other words,

$$ x *x = \begin{bmatrix}x_1^2 \\x_2^2 \\ \vdots \\x_d^2  \end{bmatrix} $$

a) Give expression for \(\nabla_{\theta} \; L_2(h(x; \theta),y)\)?

Answer: 2 * (transpose(theta) @ x + transpose(theta)@(x * x) - y)* (x + x*x).
Explanation:

$$ \begin{align} L_2(h(x;\theta),y) &= (\theta^Tx + \theta^T(x*x) - y)^2 \\ \nabla_{\theta} L_2(h(x;\theta),y) &= 2(\theta^Tx + \theta^T(x*x) - y)(x + x^2)\; . \end{align} $$

Or indirectly in the following form, which retains \(h(x; \theta)\) in the intermediate steps:

$$ \begin{align} L_2(h(x;\theta),y) &= (h(x; \theta) - y)^2 \\ \nabla_{\theta} L_2(h(x;\theta),y) &= 2(h(x; \theta) - y) \cdot \nabla_{\theta} h(x; \theta) \\ &= 2(\theta^Tx + \theta^T(x*x) - y)(x + x^2)\; . \end{align} $$

b) if

$$ h(x; \theta) = ( \theta^Tx)^2 $$

, give expression for \(\nabla_{\theta} \; L_2(h(x; \theta),y)\)?

Answer: 2((transpose(theta)@x)** 2 - y) 2(transpose(theta)@x)x.
Explanation:

$$ \begin{align} L_2(h(x,\theta),y) &= ((\theta^Tx)^2 - y)^2 \\ \nabla_{\theta} L_2(h(x,\theta),y) &= 2((\theta^Tx)^2 - y)(2((\theta^Tx)x)) \\ &= 4((\theta^Tx)^2 - y)(\theta^Tx)x \end{align} $$

c) if

$$ h(x; \theta) = (\theta*\theta)^T x $$

, give expression for \(\nabla_{\theta} \; L_2(h(x; \theta),y)\)?
Note that $ \theta*\theta$ here is computed by squaring each component in the paramter vector \(\theta\). In other words,

$$ \theta * \theta = \begin{bmatrix} \theta_1^2 \\ \theta_2^2 \\ \vdots \\ \theta_d^2  \end{bmatrix} $$

Answer: 2(transpose(theta theta)@x - y)* 2(thetax).
Explanation:

$$ \begin{align} L_2(h(x;\theta),y) &= (h(x; \theta) - y)^2 \\ \nabla_{\theta} L_2(h(x;\theta),y) &= 2(h(x; \theta) - y) \cdot \nabla_{\theta} h(x; \theta) \\ &= 2((\theta * \theta)^T x - y) \cdot 2 (\theta * x) \;\; . \end{align} $$

How did we get \(\nabla_\theta (\theta * \theta)^T x = 2 (\theta * x)\)?

This can be seen by component-wise expansion of the derivative. Without loss of generality, consider the partial derivative of \(\left(\theta * \theta \right)^T x\) with respect to its first component \(\theta_1\):

$$ \frac{\partial}{\partial \theta_1}(\theta * \theta)^Tx = \frac{\partial}{\partial \theta_1} \sum_{i=1}^{|\theta|}\theta_i^2 x_i = 2\theta_1 x_1. $$

We can then see that the \(i\)th component should be \(2 \theta_i x_i\), and that the full vector \(\nabla_\theta \left( \theta * \theta \right)^T x = 2\left( \theta * x \right)\), as desired.

Problem 5 Stochastic gradient descent in 1D

Consider a 1D regression problem without an offset \(\theta_0\), which forces the graph of the hypothesis to go through the point \(x = 0, y = 0.\) There is one parameter \(\theta\) in this model, and our hypothesis is \(h(x; \theta) = \theta x\) where we can treat \(x\) and \(\theta\) as scalars for simplicity.

Our data set \(\mathcal{D} = \{ (x^{(i)}, y^{(i)})\}_{i=1}^n\) has \(n=2\) data points:

$$ \mathcal{D} = \{(1, 1), (1, -1)\}\; . $$

a) What value of \(\theta\) minimizes the mean squared loss for this dataset? (You should be able to solve for this \(\theta\) value by hand.)

Answer: 0.
Explanation: Intuitively, mean squared loss is minimized by the line that cuts through the middle of the two points. More rigorously, we have that our mean squared loss is

$$ \begin{align} \frac{1}{n} \sum_{i=1}^n L_2(x^{(i)}, y^{(i)}; \theta) &= \frac 1 2 \left[\left(h(1;\theta) - 1\right)^2 + \left(h(1;\theta) + 1\right)^2\right]\\ &= \frac 1 2 \left[\left(\theta - 1\right)^2 + \left(\theta + 1\right)^2\right]\\ &= \frac 1 2\left[2\theta^2 + 2\right]\\ &= \theta^2 + 1, \end{align} $$

which is minimized when \(\theta=0\).

b) Starting with an initial guess of \(\theta = 1\), and letting learning rate be \(\eta = 0.2\), what are the values of \(\theta\) after the first step of batch gradient descent and after the second steps of batch gradient descent? (Here, each "batch" will evaluate all points in the dataset once, for each step of batch gradient descent.)

Answer: [.6,.36].
Explanation: \(\theta' = \theta - \eta \big((\theta - 1) + (\theta + 1)\big)\) then we will get
\(\theta' = 1 - 0.2 * 2 = 0.6\)
\(\theta'' = 0.6 - 0.2 * (0.6 - 1 + 0.6 + 1) = 0.6 - 0.24 = 0.36\)

c) Now let’s consider a variation on SGD. Each step of SGD will pick exactly one datapoint, and will strictly alternate between our two data points (rather than randomly pick one datapoint to use).

We will start with \(\theta = -1/9\) and use a fixed learning rate \(\eta = 0.2.\) Assume that we start with the data point \((1, 1)\). Now, what are the values of \(\theta\) resuling from the first four steps of this modified SGD?

Assume that our SGD takes a step of the form:

$$ \theta' = \theta - 2 \eta (\theta x^{(i)}- y^{(i)}) x^{(i)} $$

where \(\theta'\) is the new value for \(\theta\) in each step, and \(i\) is selected alternately as described above.

Answer: [1/3, -0.2, 0.28, -0.232].
Explanation: We can plug in \(\theta = -\frac{1}{9}, \eta=0.2, x^{(i)} = 1, y^{(i)} = 1\) into the update rule provided above:

$$ \begin{align} \theta' &= \theta - 2 *0.2* (\theta - 1) = -1/9 - 0.4 *(-10/9) = 1/3 \\ \theta' &= \theta - 2* 0.2 *(\theta + 1) = 1/3 - 0.4* (4/3) = -1/5 = -0.2 \\ \theta' &= \theta - 2 *0.2* (\theta - 1) = -1/5 - 0.4 *(-6/5) = 7/25 = 0.28\\ \theta' &= \theta - 2* 0.2 *(\theta + 1) = 7/25 - 0.4* (32/25) = -0.232 \end{align} $$

Probelm 6 where2meet?

A group of friends is planning to host a pset group session over the weekend. They want to find a location for the meeting that minimizes the sum of squared distances from their rooms to the location of the meeting. Assume for now that they can host the gathering at any location in the hallway.

Assuming that the friends live in a 1-dimensional hallway, solve the following problems:

a) Pose this problem as an (unconstrained) optimization problem. Assume there are \(n\) friends and the \(i\)-th friend is located at location \(l_i\). Denote the location of the meeting by \(p\). What is the objective as a function of \(p\)? Write it down. If you are having trouble deriving the general case, try the \(n=2\) case first.

Answer: The objective function is \(J(p) = &Sum_{i=1}^{n}(l_i-p)^2\), or some multiple of it such as \(J(p) = \frac{1}{n}&Sum_{i=1}^{n}(l_i-p)^2\).

b) Determine the gradient (write down/show your computation). Use it to find the optimal location \(p^{opt}\) for the meeting by setting the gradient equal to zero and solving. Does this match your intution for where the optimal location would be?

(Hint: remember the chain rule!)

Answer: \(dJ(p)/dp = 2np - 2 &Sum_{i=1}^{n}l_i\).

Explanation: The gradient is \(dJ(p)/dp = 2np - 2 &Sum_{i=1}^{n}l_i\). If we set the gradient equal to \(0\), the solution is when \(p\) is the mean of the locations (i.e., \(\frac{1}{n} &Sum_{i=1}^{n} l_i\)).

c) Let's say the \(j\)-th friend in the group will have some difficulty traveling large distances during the planned meeting time. Will the objective function in its current form take into account this detail? How might you adjust the objective function such that the optimization procedure prioritizes a solution closer to friend \(j\)?

Answer: No.
Explanation: The optimization function will not take this into account. We could multiply the \((l_j - p)^2\) term in the loss function by a constant \(&lambda > 1\). Higher values of lambda will prioritize a solution closer to friend j.

Problem 7 Objective Functions

We use gradient descent to minimize an objective function. In ML, we typically either use a standard objective function, or we design our own objective functions for specific applications. The choice of objective function is critical, since this specifies our optimization target. This choice is one of many technical decisions in which we encode human values (with or without intentionality!).

When we prioritize one objective or value, we inevitably introduce trade-offs with others. We’ll take a look at this by considering two common objective functions: L1 loss, or Mean Absolute Error (MAE), and L2 loss, or Mean Squared Error (MSE).

Say you have \(n\) data points \((x^{(i)}, y^{(i)})\), and you’re trying to fit the parameters \(\theta\) of a function \(f_\theta(x^{(i)})\) such that you can predict \(y^{(i)}\) from \(x^{(i)}\). When using the L1 objective function, we minimize the absolute differences between target values \(y^{(i)}\) and predicted values \(f_\theta(x^{(i)})\).

$$ J_1(\theta) = \frac{1}{n}\sum_{i=1}^n |y^{(i)} - f_\theta(x^{(i)})| $$

When using the L2 objective function, we minimize the squared differences between target values \(y^{(i)}\) and predicted values \(f_\theta(x^{(i)})\).

$$ J_2(\theta) = \frac{1}{n}\sum_{i=1}^n (y^{(i)} - f_\theta(x^{(i)}))^2 $$

a) Which of these loss functions do you think will be more sensitive to outliers?

Answer: L2.
Explanation: Since the difference is squared, L2 loss is much more sensitive to outliers. Imagine you are trying to fit a line to some data, and most of your points can be fit to a line with error \(&epsilon < 1\), but one point has large error \(&Epsilon>>1\). While both losses are affected by the outlier, the effect is linear in L1 and squared in L2.

Although absolute error (L1 loss) is not differentiable everywhere (the derivative is not defined when the error is 0), it is still possible to run gradient-descent methods on it, with some success. However, the optimization can be unstable in the sense that it doesn’t naturally take smaller steps as it gets close to an optimum.

b) Consider just minimizing the function \(f_2(\theta) = (3 - \theta)^2\) vs optimizing the function \(f_1(\theta) = |3 - \theta|\). What is the gradient in each case when \(\theta = 4\)? When \(\theta = 3.1\)? When \(\theta = 3.01\)? For the same step-size, which function do you think gradient descent will be more likely to "overshoot", if we start at an initial point close to \(\theta = 3\)?

Explanation: Gradient descent dynamics associated with the L2 loss are more stable, because as we get closer to \(&Theta=3\), the optimum, the magnitude of the L2's gradient \((6-2&Theta)\) is getting smaller and smaller, whereas for the L1 loss, except for exactly at \(&Theta=3\), the gradient is always of magnitude 1.

Given that L1 has larger gradient near \(&Theta=3\), it is more likely to overshoot. To handle overshooting, you can use techniques like decaying the learning rate.

c) Imagine you have a dataset consisting of different patients' reactions to a treatment for a certain disease. Suppose that 95% of the population display some typical positive response to the treatment, while 5% of the population have some genetic trait that causes a life-threatening reaction to the treatment. What are some advantages and disadvantages of each of these loss functions if they were used to fit a function \(f_\theta\) on the reaction data to determine the dosage level of the medication?

Answer: It depends!
Explanation: Would you prefer a “better” model for the 95%? If so, there’s an argument to be made for using L1 loss, to minimize the effect of the “outlier” 5%. Would you prefer a model which gives more weight to the 5% whose lives would be threatened by an incorrect result, but which might be worse for the 95% as a consequence? If so, L2 loss is likely a better choice.


Note: it’s important that students don’t come away from this thinking “L1 is fair” and “L2 is biased”. This choice has pros and cons; L1 is less stable and has multiple solutions, and is thus harder to fit.

A note below further comments on the public health perspective on this question, and how it might be handled in the real world:

For people who really build medical applications, they would not likely adopt a decision or support system that “causes a life-threatening reaction” in 5% of the patients. Instead, you would try to identify a genetic test that identifies the set of patients for whom the treatment is appropriate. There is some threshold level of risk that is considered acceptable (e.g., if the test is imperfect), but it depends on how bad the disease is, how effective the treatment is for the 95%, and how deadly it is for the 5%. This often becomes a major public health argument. E.g., polio vaccines that cause polio in a very small fraction of those getting them. But usually that fraction needs to be far, far smaller than 5%!
