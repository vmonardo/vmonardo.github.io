Intro to Data¶

Course: Introduction to Machine Learning
Lab theme: Before we train a model, we need to understand the data.

In this section, you will load a CSV file, inspect a pandas DataFrame, and make scatter plots with matplotlib. The target label is the penguin species, and the numeric columns are physical measurements that could be used as model features.

This first lab is intentionally light on machine learning. The goal is to build the basic data-handling and visualization habits you will use all semester. 🐧

Learning goals¶

By the end of the lab, you should be able to:

  1. Load a CSV file into a pandas DataFrame.
  2. Inspect rows, columns, data types, summary statistics, and missing values.
  3. Make scatter plots with matplotlib.
  4. Color points by a class label.
  5. Explain the difference between features and a label in a classification problem.

Exercise 4 — Make a scatter plot colored by class label¶

A scatter plot shows the relationship between two numeric features. Here, each point is one penguin.

We will group the data by species. matplotlib will automatically give each group a different color.

In [12]:
def scatter_by_species(data, x_col, y_col, title):
    # Make a scatter plot of two numeric columns, grouped by penguin species.
    fig, ax = plt.subplots(figsize=(7, 5))

    for species, group in data.groupby("species"):
        ax.scatter(
            group[x_col],
            group[y_col],
            label=species,
            alpha=0.75,
        )

    ax.set_title(title)
    ax.set_xlabel(x_col.replace("_", " ").title())
    ax.set_ylabel(y_col.replace("_", " ").title())
    ax.legend(title="Species")
    ax.grid(True, alpha=0.3)
    plt.show()

The point is not to build the most accurate possible model. The point is to practice turning a dataset into a well-defined machine learning task, making defensible design choices, and explaining the tradeoffs.

ML Lifecycle Step 1 — Task specification¶

A machine learning task is more than “use ML on a dataset.”

A clear task definition should identify:

  • the target/label, if there is one;
  • the features;
  • the learning type: supervised, unsupervised, or both;
  • the problem type: regression, classification, clustering, anomaly detection, etc.;
  • a metric that matches the use case;
  • a possible deployment setting;
  • possible risks, including data leakage, bias, or misuse.

Below are examples of possible tasks. You are expected to add or modify at least one.

ML Lifecycle Step 2 — Helper functions for training and evaluation¶

You do not need to understand every line in the helper functions. Focus on how the functions are used.

The helpers do four lifecycle steps:

  1. build the feature matrix X and label vector y,
  2. split into training and test sets,
  3. preprocess numeric and categorical columns,
  4. train and evaluate a simple model.
In [29]:
def make_one_hot_encoder():
    """Create a OneHotEncoder that works across several scikit-learn versions."""
    try:
        return OneHotEncoder(handle_unknown="ignore", sparse_output=False)
    except TypeError:
        return OneHotEncoder(handle_unknown="ignore", sparse=False)


def validate_features(df, target, feature_columns):
    if target is not None and target in feature_columns:
        raise ValueError(
            f"Target leakage: target column '{target}' appears in the feature list."
        )

    missing = [col for col in feature_columns if col not in df.columns]
    if target is not None and target not in df.columns:
        missing.append(target)

    if missing:
        raise ValueError(f"These columns are not in the dataframe: {missing}")


def make_xy(df, target, feature_columns):
    validate_features(df, target, feature_columns)

    use_cols = list(feature_columns) + [target]
    data = df[use_cols].dropna().copy()
    X = data[feature_columns].copy()
    y = data[target].copy()

    return X, y, data


def build_preprocessor(X):
    numeric_features = X.select_dtypes(include=[np.number]).columns.tolist()
    categorical_features = [col for col in X.columns if col not in numeric_features]

    numeric_transformer = Pipeline([
        ("imputer", SimpleImputer(strategy="median")),
        ("scaler", StandardScaler()),
    ])

    categorical_transformer = Pipeline([
        ("imputer", SimpleImputer(strategy="most_frequent")),
        ("onehot", make_one_hot_encoder()),
    ])

    preprocessor = ColumnTransformer([
        ("numeric", numeric_transformer, numeric_features),
        ("categorical", categorical_transformer, categorical_features),
    ])

    return preprocessor, numeric_features, categorical_features


def build_supervised_pipeline(X, problem_type):
    preprocessor, numeric_features, categorical_features = build_preprocessor(X)

    if problem_type == "regression":
        model = Ridge(alpha=1.0)
    elif problem_type == "classification":
        model = LogisticRegression(max_iter=2000)
    else:
        raise ValueError("problem_type must be 'regression' or 'classification'.")

    pipeline = Pipeline([
        ("preprocess", preprocessor),
        ("model", model),
    ])

    return pipeline, numeric_features, categorical_features


def train_and_evaluate_supervised(
    df,
    target,
    feature_columns,
    problem_type,
    test_size=0.25,
    random_state=RANDOM_STATE,
    verbose=True,
):
    X, y, data = make_xy(df, target, feature_columns)

    if problem_type == "classification":
        class_counts = y.value_counts()
        stratify_y = y if class_counts.min() >= 2 else None
    else:
        stratify_y = None

    X_train, X_test, y_train, y_test = train_test_split(
        X,
        y,
        test_size=test_size,
        random_state=random_state,
        stratify=stratify_y,
    )

    pipeline, numeric_features, categorical_features = build_supervised_pipeline(
        X_train, problem_type
    )
    pipeline.fit(X_train, y_train)
    y_pred = pipeline.predict(X_test)

    if problem_type == "regression":
        baseline_pred = np.repeat(y_train.mean(), len(y_test))

        metrics = {
            "problem_type": "regression",
            "target": target,
            "n_rows_used": len(data),
            "n_train": len(X_train),
            "n_test": len(X_test),
            "model": "Ridge regression",
            "baseline_MAE": mean_absolute_error(y_test, baseline_pred),
            "model_MAE": mean_absolute_error(y_test, y_pred),
            "baseline_RMSE": np.sqrt(mean_squared_error(y_test, baseline_pred)),
            "model_RMSE": np.sqrt(mean_squared_error(y_test, y_pred)),
            "model_R2": r2_score(y_test, y_pred),
        }
    elif problem_type == "classification":
        majority_class = y_train.value_counts().idxmax()
        baseline_pred = np.repeat(majority_class, len(y_test))

        metrics = {
            "problem_type": "classification",
            "target": target,
            "n_rows_used": len(data),
            "n_train": len(X_train),
            "n_test": len(X_test),
            "model": "Logistic regression",
            "baseline_accuracy": accuracy_score(y_test, baseline_pred),
            "model_accuracy": accuracy_score(y_test, y_pred),
            "model_balanced_accuracy": balanced_accuracy_score(y_test, y_pred),
            "model_macro_F1": f1_score(y_test, y_pred, average="macro"),
        }
    else:
        raise ValueError("problem_type must be 'regression' or 'classification'.")

    artifacts = {
        "pipeline": pipeline,
        "X_train": X_train,
        "X_test": X_test,
        "y_train": y_train,
        "y_test": y_test,
        "y_pred": y_pred,
        "numeric_features": numeric_features,
        "categorical_features": categorical_features,
    }

    if verbose:
        print(f"Numeric features: {numeric_features}")
        print(f"Categorical features: {categorical_features}")

        if problem_type == "classification":
            print("\nClassification report:")
            print(classification_report(y_test, y_pred))

    return pipeline, metrics, artifacts


def plot_regression_predictions(y_test, y_pred, title="Predicted vs Actual"):
    plt.figure(figsize=(6, 5))
    plt.scatter(y_test, y_pred, alpha=0.8)
    min_val = min(np.min(y_test), np.min(y_pred))
    max_val = max(np.max(y_test), np.max(y_pred))
    plt.plot([min_val, max_val], [min_val, max_val], linestyle="--")
    plt.xlabel("Actual")
    plt.ylabel("Predicted")
    plt.title(title)
    plt.tight_layout()
    plt.show()


def plot_classification_confusion_matrix(artifacts, title="Confusion Matrix"):
    y_test = artifacts["y_test"]
    y_pred = artifacts["y_pred"]
    labels = sorted(pd.Series(y_test).unique())

    cm = confusion_matrix(y_test, y_pred, labels=labels)
    disp = ConfusionMatrixDisplay(confusion_matrix=cm, display_labels=labels)
    disp.plot(xticks_rotation=45)
    plt.title(title)
    plt.tight_layout()
    plt.show()


def compare_supervised_feature_sets(df, target, feature_sets, problem_type):
    rows = []

    for feature_set_name, feature_columns in feature_sets.items():
        _, metrics, _ = train_and_evaluate_supervised(
            df=df,
            target=target,
            feature_columns=feature_columns,
            problem_type=problem_type,
            verbose=False,
        )
        metrics = metrics.copy()
        metrics["feature_set"] = feature_set_name
        metrics["n_features"] = len(feature_columns)
        rows.append(metrics)

    return pd.DataFrame(rows)

ML Lifecycle Step 5 — Task C: Unsupervised clustering¶

For this task, do not give the model the species labels during training.

The question is:

If we cluster penguins using only body measurements, do the clusters line up with species?

This is an unsupervised learning task during training. After training, you may compare clusters to the known species labels for interpretation.

def run_kmeans_clustering(
    df,
    feature_columns,
    n_clusters=3,
    compare_to=None,
    random_state=RANDOM_STATE,
):
    validate_features(df, target=None, feature_columns=feature_columns)

    data = df[feature_columns + ([compare_to] if compare_to is not None else [])].dropna().copy()
    X = data[feature_columns].copy()

    numeric_features = X.select_dtypes(include=[np.number]).columns.tolist()
    if numeric_features != feature_columns:
        raise ValueError("For this clustering helper, use numeric feature columns only.")

    scaler = StandardScaler()
    X_scaled = scaler.fit_transform(X)

    kmeans = KMeans(
        n_clusters=n_clusters,
        random_state=random_state,
        n_init=10,
    )
    clusters = kmeans.fit_predict(X_scaled)

    assignments = data.copy()
    assignments["cluster"] = clusters

    results = {
        "n_clusters": n_clusters,
        "n_rows_used": len(assignments),
        "features": ", ".join(feature_columns),
        "silhouette_score": silhouette_score(X_scaled, clusters),
    }

    if compare_to is not None:
        results[f"adjusted_rand_vs_{compare_to}"] = adjusted_rand_score(
            assignments[compare_to],
            assignments["cluster"],
        )

    return assignments, results, kmeans, scaler


def plot_clusters(assignments, x_col, y_col, cluster_col="cluster", title="Cluster plot"):
    plt.figure(figsize=(6, 5))
    plt.scatter(assignments[x_col], assignments[y_col], c=assignments[cluster_col], alpha=0.8)
    plt.xlabel(x_col)
    plt.ylabel(y_col)
    plt.title(title)
    plt.tight_layout()
    plt.show()
