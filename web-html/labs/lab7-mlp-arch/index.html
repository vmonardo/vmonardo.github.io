Step 4. From Linear to Nonlinear Models¶

A linear map looks like:

$z \mapsto Wz + b$

If you stack only linear maps, the result is still linear. To build a nonlinear function, we add an activation function such as ReLU:

$z \mapsto \sigma(Wz + b)$

An MLP repeats this pattern several times. For classification with 10 classes, the final output is a vector of 10 logits.

Step 5. Define an MLP as nn.Module¶

A PyTorch model is a class that inherits from nn.Module.

You implement:

  • __init__, where you create layers and learnable tensors
  • forward, where you define how input flows through the layers

Because images are 2D grids, we first flatten them: 28 x 28 = 784.

Checkpoint: Define the Model¶

The model builds a nonlinear function by repeating:

$z \mapsto \sigma(Wz + b)$

Each nn.Linear stores a weight matrix and bias vector. ReLU is the activation function.

Question: in your own words, what does ReLU do to negative numbers?

In [5]:
class SimpleMLP(nn.Module):
    def __init__(self, input_dim: int = 784, hidden_dim: int = 128, num_classes: int = 10):
        super().__init__()
        # First linear layer: 784 -> hidden_dim
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        # Activation (fixed nonlinearity)
        self.act = nn.ReLU()
        # Second linear layer: hidden_dim -> 10 logits
        self.fc2 = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        # x: (batch, 1, 28, 28)
        x = x.view(x.size(0), -1)   # -> (batch, 784)
        h = self.act(self.fc1(x))   # -> (batch, hidden_dim)
        logits = self.fc2(h)        # -> (batch, 10)
        return logits

mlp_model = SimpleMLP(hidden_dim=128)
print(mlp_model)

SimpleMLP(
  (fc1): Linear(in_features=784, out_features=128, bias=True)
  (act): ReLU()
  (fc2): Linear(in_features=128, out_features=10, bias=True)
)

Step 6. Inspect Learnable Parameters¶

Everything the optimizer will update lives in model.parameters().

We will:

  • count the total number of learnable scalars
  • print each parameter's name and shape

For a linear layer with input size d_in and output size d_out, the number of parameters is (d_in + 1) * d_out. The extra +1 accounts for the bias vector.

Checkpoint: Parameter Shapes¶

This cell prints every tensor that training will update.

Look for:

  • fc1.weight, fc1.bias
  • fc2.weight, fc2.bias

Question: which parameter tensor has the largest number of values?

def count_params(model):
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

print("Total learnable parameters:", count_params(mlp_model))

Step 8. Convert Logits to Probabilities with Softmax¶

Logits are raw scores.

Softmax converts logits into a probability distribution:

$p_k = \frac{e^{\ell_k}}{\sum_j e^{\ell_j}}$

We will compute probabilities for one example and visualize them.

Checkpoint: Softmax Probabilities¶

Expected output: the printed sum of probabilities should be 1.0, up to tiny rounding error.

Question: does the bar chart show one dominant class or many similar probabilities?

Remember that this is still an untrained model, so we should not expect a confident or correct prediction yet.

In [8]:
i = 0
one_logits = logits[i]              # (10,)
probs = F.softmax(one_logits, dim=0)

print("True label:", int(y_batch[i]))
print("True class:", class_names[int(y_batch[i])])
print("Top prediction:", int(probs.argmax()), "-", class_names[int(probs.argmax())])
print("Sum of probabilities:", float(probs.sum()))

plt.figure(figsize=(10, 3))
plt.bar(range(10), probs.detach().numpy())
plt.xticks(range(10), class_names, rotation=45, ha="right")
plt.ylabel("probability")
plt.title("Softmax probabilities for one image")
plt.tight_layout()
plt.show()

True class: Bag
Top prediction: 0 - T-shirt/top
Sum of probabilities: 1.0
