Lab 6. Logistic Regression¶

In this lab, you will get hands-on experience with logistic regression for image classification.

Specifically, we will go through the following steps:

  • Load the FashionMNIST dataset and inspect the class labels.
  • Visualize labeled image examples.
  • Convert each 28x28 image into a feature vector.
  • Train a binary logistic regression model with a sigmoid decision rule.
  • Train a multiclass logistic regression model with a softmax decision rule.
  • Evaluate performance using classification error on train and test data.
  • Inspect learned weights to understand what the classifier is using.

The main goal is to connect the lecture ideas of scores, probabilities, and discrete decisions to a concrete classification problem.

Step 1. Loading the Dataset¶

FashionMNIST is a supervised classification dataset. Each example contains:

  1. Input - a 28x28 grayscale image of a clothing item
  2. Label - an integer representing the correct clothing category

The training set is used to fit the model parameters. The test set is held out until evaluation, so it gives us a better estimate of performance on unseen examples.

def show_samples(dataset, indices, title="Samples"):
    cols = len(indices)
    plt.figure(figsize=(2.6 * cols, 2.8))
    for j, idx in enumerate(indices):
        img, y = dataset[idx]  # img is PIL.Image, y is int
        plt.subplot(1, cols, j + 1)
        plt.imshow(np.array(img), cmap="gray")
        plt.title(f"{class_names[y]}\n(idx={idx})", fontsize=10)
        plt.axis("off")
    plt.suptitle(title, y=1.02)
    plt.tight_layout()
    plt.show()

Step 3. Feature Engineering: Flatten and Scale Images¶

The FashionMNIST images start as 28x28 arrays of pixel values. Logistic regression expects each input to be a single feature vector.

In the cell below, we will prepare the data by:

  1. converting image tensors to NumPy arrays
  2. scaling pixel values from 0-255 down to 0-1
  3. flattening each 28x28 image into a 784-dimensional feature vector

After this step, X_train and X_test contain numeric feature matrices, and y_train and y_test contain class labels.

In [6]:
X_train = train_ds.data.numpy().astype(np.float32) / 255.0
y_train = train_ds.targets.numpy().astype(np.int64)
X_test  = test_ds.data.numpy().astype(np.float32) / 255.0
y_test  = test_ds.targets.numpy().astype(np.int64)

X_train = X_train.reshape(len(X_train), -1)
X_test  = X_test.reshape(len(X_test),  -1)

mean = X_train.mean(axis=0, keepdims=True)
std  = X_train.std(axis=0, keepdims=True) + 1e-6
X_train = (X_train - mean) / std
X_test  = (X_test  - mean) / std

Step 4. Binary Classification with Logistic Regression¶

We begin with a simpler classification problem using only two classes.

Binary classification lets us focus on the basic structure of logistic regression:

  • compute one linear score
  • convert that score into a probability with a sigmoid
  • turn the probability into a class prediction

After this section, we will return to the full multiclass dataset.

Note: Binary Classification Setup¶

For the binary task, we keep only two FashionMNIST categories:

  • T-shirt/top
  • Sneaker

This gives us a clean two-class problem. The original labels are converted into 0 and 1, where one class is treated as the negative class and the other is treated as the positive class.

The cell below creates the binary dataset.

It does three things:

  1. selects only examples whose labels are in binary_classes
  2. creates new training and test arrays for the binary task
  3. converts the labels into 0/1 values

This is the classification version of defining the task before fitting the model.

Step 5. Fit a Binary Logistic Regression Model¶

Use sklearn's LogisticRegression to fit the binary training data.

For each input vector x, the model computes a linear score:

$z = w^T x + b$

The sigmoid function converts this score into a probability:

$\sigma(z) = rac{1}{1 + e^{-z}}$

A value close to 1 means the model is more confident in class 1. A value close to 0 means the model is more confident in class 0.

    penalty="l2",
    solver="lbfgs",
    max_iter=300,

clf_bin.fit(X_train_bin, y_train_bin)

Step 6. Evaluating Binary Classification¶

Now, let's ask the model to make predictions on the training and test sets.

We will calculate classification error:

classification error = fraction of incorrect predictions

This metric treats each example as either correct or incorrect. Comparing train error and test error helps us reason about generalization.

In [9]:
train_pred_bin = clf_bin.predict(X_train_bin)
test_pred_bin  = clf_bin.predict(X_test_bin)

print("Binary train error:", np.mean(train_pred_bin != y_train_bin))
print("Binary test  error:", np.mean(test_pred_bin  != y_test_bin))

Binary test  error: 0.0015

Step 7. Inspecting Scores and Sigmoid Probabilities¶

In the cell below, we look at the model outputs before and after the sigmoid transformation.

For binary logistic regression:

  • decision_function(x) returns the raw score z
  • predict_proba(x) returns the probability for each class
  • probabilities greater than or equal to 0.5 are assigned to class 1
  • probabilities less than 0.5 are assigned to class 0

This shows how logistic regression turns a continuous score into a discrete classification decision.

In [10]:
z_bin = clf_bin.decision_function(X_test_bin[:5])
p_bin = clf_bin.predict_proba(X_test_bin[:5])

print("Scores z:", z_bin)
print("Sigmoid probabilities:", p_bin[:,1])

Note: Visualizing the Binary Model Weights¶

Because each image was flattened into 784 features, the model learns 784 weights.

Those 784 weights correspond to the 28x28 pixel locations in the original image. If we reshape the weight vector back into a 28x28 image, we can see which pixels push the score toward one class or the other.

How to read the weight image:

  • bright pixels have positive weights and push the score toward class 1
  • dark pixels have negative weights and push the score toward class 0
  • pixels near zero have little effect on the score

Note: Local Interpretability for One Prediction¶

The weight image gives a global view of the model. It tells us what the model tends to use across many examples.

We can also inspect one prediction at a time. For a single image, the score is:

$z = \sum_i w_i x_i + b$

The elementwise product w * x shows the contribution from each pixel in that one image.

In [12]:
# Pick one test example to analyze
i = 0
x_img = X_test_bin[i].reshape(28, 28)
y_true = y_test_bin[i]

z = clf_bin.decision_function(X_test_bin[i:i+1])[0]
p1 = clf_bin.predict_proba(X_test_bin[i:i+1])[0, 1]
y_pred = clf_bin.predict(X_test_bin[i:i+1])[0]

contrib = (clf_bin.coef_[0] * X_test_bin[i]).reshape(28, 28)  # w ⊙ x

plt.figure(figsize=(10,3.2))

plt.subplot(1,3,1)
plt.imshow(x_img)
plt.title(f"Input image\ntrue y={y_true}")
plt.axis("off")

plt.subplot(1,3,2)
plt.imshow(w)
plt.title("Weights w")
plt.axis("off")

plt.subplot(1,3,3)
plt.imshow(contrib)
plt.title("Contribution map (w ⊙ x)")
plt.axis("off")

Step 8. Multiclass Classification with Softmax¶

Now we return to the full FashionMNIST dataset with all ten classes.

The core idea is the same as in binary classification, but the model now computes one score per class instead of one total score.

For multiclass classification:

  • the model produces a vector of scores
  • softmax converts the scores into class probabilities
  • the predicted class is the one with the largest score or probability

Step 9. Fit a Multiclass Logistic Regression Model¶

Use sklearn's LogisticRegression to fit the full ten-class classification problem.

For each input x, the model computes a score for every class:

$z_k = w_k^T x + b_k$

The softmax function converts the score vector into probabilities that sum to 1:

$\mathrm{softmax}(z)_k = rac{e^{z_k}}{\sum_j e^{z_j}}$

As in the previous lab, we also use L2 regularization with penalty="l2".

Step 5. Fit a Binary Logistic Regression Model¶

Use sklearn's LogisticRegression to fit the binary training data.

For each input vector x, the model computes a linear score:

$z = w^T x + b$

The sigmoid function converts this score into a probability:

$\sigma(z) = rac{1}{1 + e^{-z}}$

A value close to 1 means the model is more confident in class 1. A value close to 0 means the model is more confident in class 0.

Step 8. Multiclass Classification with Softmax¶

Now we return to the full FashionMNIST dataset with all ten classes.

The core idea is the same as in binary classification, but the model now computes one score per class instead of one total score.

For multiclass classification:

  • the model produces a vector of scores
  • softmax converts the scores into class probabilities
  • the predicted class is the one with the largest score or probability

Step 9. Fit a Multiclass Logistic Regression Model¶

Use sklearn's LogisticRegression to fit the full ten-class classification problem.

For each input x, the model computes a score for every class:

$z_k = w_k^T x + b_k$

The softmax function converts the score vector into probabilities that sum to 1:

$\mathrm{softmax}(z)_k = rac{e^{z_k}}{\sum_j e^{z_j}}$

As in the previous lab, we also use L2 regularization with penalty="l2".
