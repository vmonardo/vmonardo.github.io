Lab 1. Intro to Data¶

In this lab, you will get hands-on experience with the first stage of a machine learning workflow: understanding the data.

Specifically, we will go through the following steps:

  • Load the Palmer Penguins dataset with pandas.
  • Inspect rows, columns, data types, summary statistics, and missing values.
  • Make scatter plots with matplotlib.
  • Color points by a class label.
  • Identify the difference between features and a label in a classification problem.

This lab is intentionally light on model training. The goal is to build the data-handling and visualization habits you will use before every modeling task.

Step 4. Make a Scatter Plot Colored by Class Label¶

A scatter plot shows the relationship between two numeric features. Here, each point is one penguin.

We group the data by species, so each species gets a different color. This lets us ask whether the numeric measurements visually separate the classes.

In [12]:
def scatter_by_species(data, x_col, y_col, title):
    # Make a scatter plot of two numeric columns, grouped by penguin species.
    fig, ax = plt.subplots(figsize=(7, 5))

    for species, group in data.groupby("species"):
        ax.scatter(
            group[x_col],
            group[y_col],
            label=species,
            alpha=0.75,
        )

    ax.set_title(title)
    ax.set_xlabel(x_col.replace("_", " ").title())
    ax.set_ylabel(y_col.replace("_", " ").title())
    ax.legend(title="Species")
    ax.grid(True, alpha=0.3)
    plt.show()
