Homework: LIME patches — MobileNet “dog score” on a photo

You will load a TF.js MobileNet v1 (0.25×224), preprocess the input consistently with the model, then implement the core pieces of LIME (Local Interpretable Model-agnostic Explanations) using a grid of patch masks (a simple stand-in for superpixels).

The scalar you explain is the softmax mass for the target ImageNet dog-breed class. Positive LIME coefficients should align with regions that increase that score (e.g. the dog’s face).

References (read at least the paper abstract + surrogate section)

  • Ribeiro, Singh, Guestrin, “Why Should I Trust You?” Explaining the Predictions of Any Classifier (LIME)
  • scikit-learn Ridge — weighted least squares via sample_weight.

def ensure_tfjs_model(model_json_url: str, cache_dir: pathlib.Path) -> pathlib.Path:
    cache_dir.mkdir(parents=True, exist_ok=True)
    base = model_json_url.rpartition("/")[0] + "/"
    local_json = cache_dir / "model.json"

    def fetch(url: str, dest: pathlib.Path) -> None:
        if dest.exists():
            return
        dest.parent.mkdir(parents=True, exist_ok=True)
        with urllib.request.urlopen(url) as resp, open(dest, "wb") as f:
            f.write(resp.read())

    fetch(model_json_url, local_json)
    manifest = json.load(open(local_json))["weightsManifest"]
    for g in manifest:
        for name in g["paths"]:
            fetch(base + name, cache_dir / name)
    return local_json

def preprocess(pil: Image.Image) -> np.ndarray:

Interpretable patches (make_patches)¶

LIME explains a simple representation of the input. Here each feature is a fixed grid patch: value 1 = keep original pixels, 0 = replace with a baseline (grey in normalized space: LIME_BASELINE).

We build a list patches where each entry is (row_index_grid, col_index_grid) for one patch — see numpy.meshgrid.

In [105]:
def make_patches(h: int, w: int, ps: int):
    out = []
    for r in range(0, h, ps):
        for c in range(0, w, ps):
            rows = np.arange(r, min(r + ps, h))
            cols = np.arange(c, min(c + ps, w))
            rr, cc = np.meshgrid(rows, cols, indexing="ij")
            out.append((rr, cc))
    return out

Masking: turn binary features into images (apply_mask)¶

Given a binary vector m (one entry per patch), zero out patches where m[j] == 0 by assigning baseline to those pixels. This is how a single perturbed input is built for the black-box model.

  • TODO: loop over j, keep in enumerate(m); when keep is false, set z[rr, cc, :] = baseline using patches[j].
In [106]:
def apply_mask(img: np.ndarray, m: np.ndarray, patches, baseline=LIME_BASELINE) -> np.ndarray:
    z = img.copy()
    for j, keep in enumerate(m):
        if not keep:
            rr, cc = patches[j]
            z[rr, cc, :] = baseline
    return z

Sample many neighborhoods (lime_samples)¶

Draw many random binary masks so each row is one perturbed image. Use numpy.random.Generator.binomial (n=1, p≈0.6) to get roughly 60% of patches on per sample — same spirit as LIME’s random hide/show. See also np.stack.

Force masks[0] to all ones so the first sample is the original image (unoccluded).

Then stack apply_mask for every row into a batch tensor batch of shape (n_samples, H, W, 3) for predict_proba.

In [107]:
def lime_samples(img: np.ndarray, patches, n_samples: int, rng: np.random.Generator):
    n_p = len(patches)
    masks = rng.binomial(1, 0.6, (n_samples, n_p))
    masks[0] = 1
    batch = np.stack([apply_mask(img, masks[i], patches) for i in range(n_samples)])
    return masks, batch

Locality weights (kernel_w)¶

LIME weights perturbations that are close to the original (all patches on) more heavily. Use an exponential kernel on a distance: here a simple choice is Euclidean distance on (1 - masks) (how far a mask is from the all-ones vector). Smaller distance ⇒ larger weight.

Parameters: sigma controls how wide the “local” neighborhood is (try changing it after everything runs).

In [108]:
def kernel_w(masks: np.ndarray, sigma: float) -> np.ndarray:
    d = np.sqrt(((1 - masks) ** 2).sum(1))
    return np.exp(-(d**2) / (sigma**2))

Fit the local surrogate (fit_lime)¶

This is the core LIME step: weighted ridge regression predicting the scalar “dog score” from binary mask features. Use Ridge.fit(X, y, sample_weight=...) — weights come from kernel_w.

Also compute:

  • y0 — dog score on the clean image (one forward pass),
  • return the Ridge coefficients (per-patch importance), intercept, surrogate prediction at all-ones, y0, and ridge.score(...) with sample_weight (Ridge.score).

In [109]:
def fit_lime(img: np.ndarray, patches, cls: int, n_samples=800, sigma=8.0, seed=0):
    rng = np.random.default_rng(seed)
    masks, batch = lime_samples(img, patches, n_samples, rng)
    y = predict_proba(batch)[:, cls]
    w = kernel_w(masks, sigma)
    ridge = Ridge(alpha=1.0)
    ridge.fit(masks, y, sample_weight=w)
    y0 = float(predict_proba(img[None, ...])[0, cls])
    y_hat = float(ridge.predict(np.ones((1, len(patches))))[0])
    return ridge.coef_, y_hat, y0, ridge.score(masks, y, sample_weight=w)

Map coefficients to a heatmap and plot¶

Each Ridge coefficient belongs to one patch. Broadcast each coef[k] to all pixels in patches[k] to build heat with shape (224, 224).

Then plot: input | heatmap | overlay (code below is complete once heat is filled).
